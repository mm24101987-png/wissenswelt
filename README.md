# Wissenswelt – installierbare PWA

Mobile Allgemeinwissens-App mit 72 kurzen Lektionen, Multiple-Choice-Tests, Kategorien, Suche, Lernfortschritt und Wiederholung. Die Inhalte sind eigenständig formuliert.

## Veröffentlichung ohne Laptop (iPhone + Safari)

1. Auf github.com/new ein öffentliches Repository `wissenswelt` anlegen.
2. Im Repository `Add file` → `Upload files` auswählen und die Dateien aus diesem Ordner hochladen (alle Dateien direkt ins Repository-Hauptverzeichnis).
3. Unter `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` wählen; Branch `main`, Ordner `/(root)` → `Save`.
4. Nach der Bereitstellung `https://BENUTZERNAME.github.io/wissenswelt/` in Safari öffnen.
5. Safari-Teilen-Menü → `Zum Home-Bildschirm` → `Hinzufügen`.

Wichtig: Eine PWA ist erst nach Veröffentlichung unter HTTPS installierbar. Der Lernfortschritt liegt lokal im Browser und wird nicht automatisch auf andere Geräte übertragen. Nach erfolgreicher Erstinstallation kann die App offline verwendet werden.
